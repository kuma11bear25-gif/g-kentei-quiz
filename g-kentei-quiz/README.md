# G検定 問題集

JDLA シラバス（G2024#6 / 全8章）に沿ったG検定対策クイズアプリです。

## セットアップ

```bash
npm install
npm run dev
```

ブラウザで表示されるURL（通常 http://localhost:5173）を開いてください。

## ビルド（本番用ファイル生成）

```bash
npm run build
```

`dist/` フォルダに静的ファイルが出力されます。Vercel・Netlify・GitHub Pages などにそのままデプロイできます。

## 機能

- 全8章、各章の問題プールから毎回ランダムに10問出題
- 選択肢タップ→即解説表示
- 過去に正解した問題を記録し、2回正解した問題はスキップ可能
- 章ごとの最高スコア・挑戦回数をブラウザの `localStorage` に保存（同じブラウザなら次回訪問時も引き継がれます）

## 構成

- `src/App.jsx` — アプリ本体（問題データ・UIロジック）
- `src/main.jsx` — Reactのエントリーポイント
- `index.html` / `vite.config.js` — Vite（ビルドツール）の設定

## 補足

Claude.aiのアーティファクト環境で使われる `window.storage` API は、この単体プロジェクトでは使えないため、
`src/App.jsx` の冒頭で同じインターフェースを `localStorage` でラップしたシムを定義し、
アプリ本体のロジックは変更せずに動くようにしています。ブラウザのデータを消去すると進捗もリセットされます。
